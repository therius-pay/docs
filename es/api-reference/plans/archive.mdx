`DELETE /subscription/plan/{id}` archiva de forma suave un plan estableciendo su timestamp `deletedAt`. Las suscripciones existentes en el plan archivado continúan facturando normalmente. En la próxima fecha de renovación de cada suscriptor, Therius cancelará esas suscripciones en lugar de renovarlas. Ningún suscriptor nuevo puede inscribirse en un plan archivado.

<SchemaLangNote lang="es" />

<Note>
  Esto es un borrado suave — la fila del plan no se elimina de forma permanente, así que permanece en la base de datos con fines de auditoría. Sin embargo, **se excluye de los resultados de lista de `GET /subscription/plan`** una vez archivado (ese endpoint filtra los planes eliminados); consúltalo directamente vía `GET /subscription/plan/{id}` si necesitas inspeccionar un plan archivado.
</Note>

Devuelve `200 OK` con `{ "deleted": true }`.

## Errores

| Código | Significado |
| --- | --- |
| `404` | Plan no encontrado. |
| `409` | El plan ya está archivado. |

<Warning>
  Una vez que un plan está archivado, los suscriptores existentes serán cancelados automáticamente en su próxima renovación. Migra a los suscriptores a un plan nuevo usando [change-plan](/api-reference/subscriptions/change-plan) antes de archivar si quieres que continúen facturando sin interrupción.
</Warning>

<RequestExample>

```bash cURL
curl -X DELETE "https://api.therius.io/v1/subscription/plan/42?merchantCode=MERCHANT_001" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{ "deleted": true }
```

</ResponseExample>
