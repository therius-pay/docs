`GET /subscription/plan` devuelve todos los planes de facturación de tu cuenta de comercio, incluyendo el conteo actual de suscriptores y el estado de archivo de cada plan. Usa el filtro `country` para ver solo los planes disponibles en un mercado específico — los planes globales (los que no tienen restricciones de país) siempre se incluyen en los resultados filtrados.

<SchemaLangNote lang="es" />

## Solicitud

**URL base:** `https://api.therius.io/v1`

**Endpoint:** `GET /subscription/plan`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer sk_live_xxx` (producción) o `Bearer sk_sandbox_xxx` (sandbox) — tu clave de API privada de comercio.
</ParamField>

### Parámetros de consulta

<ParamField query="merchantCode" type="string" required>
  Tu identificador de cuenta de comercio. Requerido si tu clave está asociada con varias cuentas de comercio.
</ParamField>

<ParamField query="country" type="string">
  Código de país ISO 3166-1 alpha-2 para filtrar planes por disponibilidad, p. ej. `"BR"`. Devuelve planes donde `availableCountries` incluye el código dado, más todos los planes disponibles globalmente. Omítelo para devolver todos los planes independientemente de las restricciones de país.
</ParamField>

## Respuesta

Devuelve un array de objetos de plan. Cada objeto incluye todos los campos establecidos en el momento de la creación más los siguientes campos calculados:

<ResponseField name="id" type="integer">
  El ID entero único del plan.
</ResponseField>

<ResponseField name="subscriberCount" type="integer">
  Número de suscriptores actualmente activos o en prueba en este plan.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Si el plan acepta nuevos suscriptores. Establécelo en `false` vía [Actualizar plan](/api-reference/plans/update) para desactivarlo de forma suave.
</ResponseField>

<ResponseField name="deletedAt" type="string">
  Timestamp ISO 8601 de cuándo se archivó el plan, o `null` si no está archivado. Los planes archivados siguen apareciendo en los resultados de lista.
</ResponseField>

<RequestExample>

```bash cURL
curl "https://api.therius.io/v1/subscription/plan?merchantCode=MERCHANT_001&country=US" \
  -H "Authorization: Bearer sk_live_your_key_here"
```

</RequestExample>

<Tip>
  Los planes archivados se incluyen en la respuesta con un `deletedAt` no nulo. Fíltralos del lado del cliente si solo quieres los planes actualmente abiertos para inscripción.
</Tip>
