`PATCH /subscription/plan/{id}` actualiza los campos mutables de un plan existente. Puedes renombrarlo, actualizar su descripción, alternar su estado activo para dejar de aceptar nuevos suscriptores, o ajustar los países donde está disponible — todo sin afectar a los suscriptores existentes.

<SchemaLangNote lang="es" />

<Note>
  `amount`, `interval`, `intervalCount` y `currency` son inmutables y no se pueden cambiar vía este endpoint. Para cambiar el precio o la cadencia de facturación, crea un plan nuevo usando `POST /subscription/plan` y migra a los suscriptores usando [change-plan](/api-reference/subscriptions/change-plan).
</Note>

Incluye solo los campos que quieres cambiar — los omitidos se dejan sin cambios (ver el panel de parámetros de arriba para la lista completa; `availableCountries` es un reemplazo completo, no una fusión).

Devuelve `200 OK` con el objeto de plan actualizado completo.

## Errores

| Código | Significado |
| --- | --- |
| `404` | Plan no encontrado. |
| `422` | Error de validación — p. ej. un código de país no reconocido o un intento de mutar un campo inmutable. |

<RequestExample>

```bash cURL
curl -X PATCH https://api.therius.io/v1/subscription/plan/42 \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "name": "Pro Monthly (Revised)",
    "isActive": false
  }'
```

</RequestExample>
