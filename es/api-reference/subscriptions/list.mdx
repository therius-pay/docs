`GET /subscription` devuelve una lista paginada de tus suscripciones. Filtra por estado, correo o nombre del cliente, plan, bandera de tarjeta o rango de fecha de creación para acotar los resultados. Los resultados se devuelven en orden cronológico inverso por fecha de creación.

<SchemaLangNote lang="es" />

Filtra y pagina con los parámetros de consulta del panel de arriba (`created_from`/`created_to` son límites de fecha ISO 8601 inclusivos sobre `createdAt`). Forma de la respuesta:

```json
{
  "data": [ ],
  "total": 142,
  "page": 1,
  "per_page": 20
}
```

<RequestExample>

```bash cURL
curl "https://api.therius.io/v1/subscription?merchantCode=MERCHANT_001&status=active&per_page=50" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{}
```

</ResponseExample>

<Tip>
  Combina `created_from` y `created_to` con `status=past_due` para identificar a los suscriptores que se volvieron morosos dentro de una ventana específica — útil para campañas de recuperación dirigidas.
</Tip>
