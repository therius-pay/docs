`GET /subscription/{id}` devuelve el registro completo de la suscripción para un UUID dado (ver el panel de respuesta de arriba), con su plan incrustado bajo `plan`. El progreso de gestión de cobros se reporta vía `dunningAttemptCount` en la propia suscripción, no un objeto anidado — para el historial de facturas, llama a [Ver facturas](/es/api-reference/subscriptions/invoices) con el mismo `id` de suscripción; todavía no hay un endpoint separado de cronología de eventos de ciclo de vida.

<SchemaLangNote lang="es" />

## Errores

| Código | Significado |
| --- | --- |
| `404` | No se encontró ninguna suscripción para el `id` dado bajo tu cuenta de comercio. |

<RequestExample>

```bash cURL
curl "https://api.therius.io/v1/subscription/sub_abc123def456?merchantCode=MERCHANT_001" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{}
```

</ResponseExample>
