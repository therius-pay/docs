Llama a `POST /payment/{id}/capture` para liquidar fondos de un `POST /payment/authorization` anterior. Puedes capturar menos que el monto total autorizado — una captura parcial — y la retención restante se libera automáticamente. Debes llamar a este endpoint dentro de la ventana de autorización del adquirente (normalmente 7 días) o la retención expirará y necesitarás volver a autorizar.

<SchemaLangNote lang="es" />

## Identificar el pago

`{id}` es el `id` de pago de Therius devuelto en la respuesta a `POST /payment/authorization` (y `POST /payment/purchase`). Guárdalo cuando creas el pago. `orderCode` y `paymentCode` son tus propios campos de referencia — **no** se aceptan como forma de direccionar el pago para captura, reembolso o cancelación.

Un `id` que no existe, o que pertenece a otro comercio, devuelve `404`.

## Ejemplo

### Captura total

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/payment/9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e/capture \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "amount": { "currency": "USD", "value": 9900, "exponent": 2 }
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "id": "9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e",
  "status": "captured",
  "paymentCode": "PC-1234567890",
  "orderCode": "ORDER-20240101-002",
  "merchantCode": "MERCHANT_001",
  "amount": { "currency": "USD", "value": 9900, "exponent": 2 }
}
```

</ResponseExample>

### Captura parcial

```bash
curl -X POST https://api.therius.io/v1/payment/9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e/capture \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "amount": { "currency": "USD", "value": 7500, "exponent": 2 }
  }'
```

```json
{
  "id": "9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e",
  "status": "captured",
  "paymentCode": "PC-1234567890",
  "orderCode": "ORDER-20240101-002",
  "merchantCode": "MERCHANT_001",
  "amount": { "currency": "USD", "value": 7500, "exponent": 2 }
}
```

<Note>
  Cuando realizas una captura parcial, Therius libera automáticamente la retención restante (\$24.00 en el ejemplo anterior). No necesitas enviar una solicitud de cancelación separada para la porción no capturada.
</Note>

<Warning>
  Solo puedes capturar un pago autorizado una vez. Si necesitas capturar un monto diferente después de que ya se procesó una captura parcial, necesitarás crear una nueva autorización.
</Warning>

<Tip>
  Pasa siempre un `Idempotency-Key` en la captura. Si tu servidor agota el tiempo de espera y reintentas, la misma clave garantiza que no liquidarás dos veces la misma autorización.
</Tip>
