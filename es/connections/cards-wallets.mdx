Los pagos con tarjeta son el método por defecto en Therius — omite `paymentMethod` por completo de tu solicitud y se asume un pago con tarjeta. Las wallets digitales usan el mismo endpoint `POST /payment/purchase`, con un código `paymentMethod` y una carga específica de la wallet agregada a la solicitud base. Todos los métodos de tarjeta y wallet soportan tanto cobros únicos como recurrentes (de suscripción), salvo que se indique lo contrario.

<Note>
  Los métodos de wallet como Apple Pay y Google Pay requieren una conexión configurada en tu dashboard de Therius. Contacta a Therius para habilitar el descifrado de wallets para tu cuenta de comercio antes de salir a producción.
</Note>

### Tarjeta de crédito/débito — `card`

Las tarjetas son el valor por defecto universal. Se soportan todas las monedas y países. Puedes omitir `paymentMethod` por completo o establecerlo en `"card"` — ambos son equivalentes. Pasa datos de tarjeta sin procesar del lado del servidor durante las pruebas; para checkouts basados en navegador, usa un nonce de los campos alojados del SDK JS en lugar de datos de tarjeta sin procesar para mantener tu integración fuera del alcance de PCI.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 4999, "exponent": 2 },
  "card": {
    "cardData": {
      "cardNumber": "4111111111111111",
      "cardholderName": "Ada Lovelace",
      "expiryMonth": "12",
      "expiryYear": "2030",
      "cvv": "123"
    }
  }
}
```

### Apple Pay — `applepay`

Apple Pay se soporta en iOS, macOS y Safari. Usa `createWalletButton` del SDK JS para renderizar el botón de Apple Pay y lanzar la hoja de pago. El token de pago sin procesar devuelto por `ApplePaySession` va en `walletData.token`. Apple Pay soporta cobros recurrentes.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "applepay",
  "walletData": {
    "type": "applepay",
    "token": "<base64 token from ApplePaySession>"
  }
}
```

### Google Pay — `googlepay`

Google Pay funciona en Android, Chrome y cualquier navegador donde el comprador tenga una tarjeta guardada. Usa `createWalletButton` del SDK JS para renderizar el botón y recibir el token `PaymentData`. Google Pay soporta cobros recurrentes.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "googlepay",
  "walletData": {
    "type": "googlepay",
    "token": "<token from Google PaymentData>"
  }
}
```

### Click to Pay — `click_to_pay`

Click to Pay es el esquema de tarjetas guardadas a nivel de red de Visa/Mastercard, impulsado por CyberSource. El comprador selecciona una tarjeta de red guardada sin ingresar los datos de la tarjeta. Usa `createClickToPayButton` del SDK JS para renderizar el botón y obtener un nonce.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "click_to_pay",
  "card": {
    "nonceData": {
      "nonce": "<nonce from createClickToPayButton>"
    }
  }
}
```

### PayPal — `paypal`

PayPal soporta USD, EUR, GBP y muchas monedas adicionales. Es un flujo basado en redirect — el comprador es redirigido a PayPal para iniciar sesión y confirmar. La respuesta devuelve `status: "pending_action"` con `actionRequired.url`.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "paypal"
}
```

### Venmo — `venmo`

### Alipay — `alipay`

Alipay soporta CNY más 13 monedas adicionales para transacciones transfronterizas. Los compradores se autentican en la app de Alipay o vía código QR. La respuesta devuelve una URL de redirect o una carga de QR.

```json

  "orderCode": "ORDER-001",
  "amount": { "currency": "CNY", "value": 5000, "exponent": 2 },
  "paymentMethod": "alipay"
}
```

## Tokenización de wallet

Puedes guardar un método de pago de wallet para uso futuro — por ejemplo, para cobrarle a un comprador de nuevo sin requerir que se vuelva a autenticar. Para tokenizar una transacción de wallet, establece `walletData.tokenize: true` e incluye un `shopper.id` en tu solicitud. Therius almacena el token de wallet contra ese comprador y lo hace disponible para cobros posteriores.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "applepay",
  "walletData": {
    "type": "applepay",
    "token": "<base64 token from ApplePaySession>",
    "tokenize": true
  },
  "shopper": {
    "id": "SHOPPER-001"
  }
}
```

<Note>
  La tokenización de wallet requiere un `shopper.id`. Sin él, la bandera `tokenize` se ignora y no se guarda ningún token.
</Note>
