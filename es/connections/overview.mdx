Cada método de pago en Therius enruta a través del mismo endpoint `POST /payment/purchase`. Cambias entre métodos estableciendo el campo `paymentMethod` en el cuerpo de tu solicitud — u omítelo por completo al cobrar una tarjeta. Esta página es tu punto de partida para el catálogo completo de métodos de pago: explora por categoría abajo, o usa la tabla de búsqueda rápida para saltar directamente a un método específico.

<Note>
  Un método está disponible para tu cuenta una vez que una **conexión** que lo soporta está configurada y habilitada en tu dashboard (ver [Enrutamiento inteligente](/concepts/smart-routing)). El catálogo de abajo es el conjunto completo que Therius soporta — revisa la página **Conexiones** en tu dashboard para ver qué está activo en tu cuenta, y contacta a Therius para habilitar un método que no veas ahí.
</Note>

## Cómo funcionan los redirects

La mayoría de los métodos de pago alternativos (APM) devuelven un `status` de `"pending_action"` junto con un `actionRequired.url`. Tu integración debe redirigir al comprador a esa URL para que pueda completar la autenticación o el pago en la página de su banco o wallet. Después de que el comprador termina, Therius lo redirige de vuelta a tu `apm.returnUrl`.

Si estás usando el SDK JS de Therius, no necesitas manejar esto manualmente — llama a `sdk.handleAction(result.actionRequired)` y el SDK administra el redirect, espera el resultado y resuelve la promesa por ti.

<Note>
  Algunos métodos de redirect requieren campos adicionales en la solicitud — como `apm.returnUrl`, `apm.cancelUrl` o detalles del comprador como el nombre y el correo. Estos requisitos se indican en la página de cada método.
</Note>

## Forma base de la solicitud

Cada solicitud a `POST /payment/purchase` comparte la misma estructura base. Agregas un código `paymentMethod` y un objeto específico del método (`card`, `apm` o `walletData`) encima de ella.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": {
    "currency": "USD",
    "value": 5000,
    "exponent": 2
  },
  "paymentMethod": "<code>"
}
```

Los montos siempre están en unidades menores. Para USD, `value: 1999` con `exponent: 2` equivale a $19.99. Para monedas sin decimales como JPY o CLP, usa `exponent: 0` y pasa el monto entero completo.
