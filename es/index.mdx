Therius es una API de pagos que te permite aceptar tarjetas, wallets digitales y más de 40 métodos de pago alternativos — Pix, ACH, iDEAL, Klarna, Apple Pay y más — a través de un solo endpoint. Esta documentación cubre todo, desde tu primera llamada en sandbox hasta la gestión de suscripciones, el manejo de desafíos de 3D Secure y la integración del SDK JS para una recolección de tarjetas segura en el navegador.

## Cómo funciona Therius

Cada pago — tarjeta, wallet o método alternativo — fluye a través del mismo endpoint `/payment/purchase`. Eliges el método de pago pasando un campo `paymentMethod` (u omitiéndolo para tarjetas). La respuesta siempre tiene la misma forma, así que tu backend no necesita rutas de código separadas por método.

<Steps>
  <Step title="Obtén una clave de sandbox">
    Tu cuenta de Therius incluye una clave de sandbox (`sk_sandbox_...`) sin configuración. Enruta a un stub de proveedor de prueba — nada toca una red de tarjetas real.
  </Step>
  <Step title="Haz tu primera llamada de API">
    Envía tu clave como `Authorization: Bearer sk_live_...` y dispara un `POST /payment/purchase`. Ver el [Inicio rápido](/quickstart) para un comando curl listo para ejecutar.
  </Step>
  <Step title="Integra el SDK JS (si es basado en navegador)">
    Si estás aceptando tarjetas desde un navegador, usa el [SDK JS](/sdk/overview) para que los números de tarjeta sin procesar nunca transiten por tu servidor. El SDK emite un nonce de un solo uso; tu servidor cobra el nonce.
  </Step>
  <Step title="Sal a producción">
    Cambia `sk_sandbox_...` por `sk_live_...` y apunta a `api.therius.io`. No se requieren otros cambios de código.
  </Step>
</Steps>
