---
title: "Place a Fund Reserve"
sidebarTitle: "Authorize a Payment"
description: "Reserve funds without capturing. Call capture later to settle, or cancel to release the hold. Ideal for physical goods."
openapi: "POST /payment/authorization"
---

`POST /payment/authorization` reserves funds on the cardholder's account without settling them. The authorization hold is typically valid for 7 days, though the exact window depends on the acquirer and card network. Call [Capture](/api-reference/capture) to settle the funds when you're ready to fulfill, or [Cancel](/api-reference/cancel) to release the hold if you can't fulfill the order.

See the [Purchase](/api-reference/purchase) reference for the full `card`/`shopper`/response field descriptions — the request and response shape are identical, only the outcome differs (a hold instead of a settled charge).

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/payment/authorization \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "orderCode": "ORDER-20240101-002",
    "amount": { "currency": "USD", "value": 9900, "exponent": 2 },
    "card": {
      "cardData": {
        "cardNumber": "4111111111111111",
        "cardholderName": "Ada Lovelace",
        "expiryMonth": "12",
        "expiryYear": "2030",
        "cvv": "123"
      }
    }
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "id": "9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e",
  "status": "authorized",
  "paymentCode": "PC-1234567890",
  "orderCode": "ORDER-20240101-002",
  "merchantCode": "MERCHANT_001",
  "amount": { "currency": "USD", "value": 9900, "exponent": 2 },
  "card": {
    "cardData": { "brand": "visa", "cardNumber": "411111****1111", "type": "credit" },
    "networkTransactionId": "txn_def456"
  }
}
```

</ResponseExample>

<Note>
  Partial capture is supported. When you call [Capture](/api-reference/capture), you can pass an `amount` less than or equal to the authorized amount. For example, if you authorized $$99.00 but only shipped $$75.00 worth of goods, capture \$75.00 and the remaining hold is released automatically.
</Note>

<Warning>
  Authorization holds expire — typically after 7 days, but this varies by acquirer and card network. If you don't call [Capture](/api-reference/capture) before expiry, the hold is released and you'll need to re-authorize. Monitor hold age in your order management system.
</Warning>
