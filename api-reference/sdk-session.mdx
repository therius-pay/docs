---
title: "Create a Short-Lived SDK Token"
sidebarTitle: "Create an SDK Session"
description: "Exchange your private API key for a short-lived client token to initialize the Therius JS SDK in the browser safely."
openapi: "POST /sdk/session"
---

`POST /sdk/session` exchanges your merchant private API key for a short-lived JWT `clientToken` with a 30-minute TTL. Pass the `clientToken` to the browser to initialize `new TheriusSDK({ clientToken })`. Your private key never reaches the browser — it stays on your server where it belongs.

<Warning>
  Call this endpoint from your server only. Never call it from browser JavaScript or expose your private API key to the client side.
</Warning>

The request body is entirely optional — call it with no body for a bare `clientToken`. Set `country` (required as soon as you also set `amount`, `currency`, or `orderCode`) to bind the session and get back a `sessionId`. See the parameters and response panels above for the full field list.

<Note>
  The `clientToken` embeds an HMAC-SHA256 hash of your public key. Your raw private key is never present in the token payload and never reaches the browser.
</Note>

See [Session Bootstrap](/sdk/session-bootstrap) in the JS SDK tab for how to use the `clientToken` on the client side.

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/sdk/session \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "customerId": "customer-42", "country": "US", "currency": "USD", "amount": 4999 }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "clientToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 1800,
  "sessionId": "sess_abc123",
  "country": "US",
  "amount": 4999,
  "currency": "USD"
}
```

</ResponseExample>
