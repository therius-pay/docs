---
title: "Create a Subscription Plan"
sidebarTitle: "Create a Plan"
description: "Define a recurring billing plan with amount, currency, interval, trial period, and optional geographic restrictions."
openapi: "POST /subscription/plan"
---

Plans define the billing terms for subscriptions — amount, currency, interval, and optional trial period. Once a plan has active subscribers, its `amount`, `interval`, `intervalCount`, and `currency` are immutable. To change pricing or cadence for existing subscribers, create a new plan and migrate them using [change-plan](/api-reference/subscriptions/change-plan).

## Request

**Base URL:** `https://api.therius.io/v1`

**Endpoint:** `POST /subscription/plan`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer prv_production_xxx` (production) or `Bearer prv_sandbox_xxx` (sandbox) — your merchant private API key.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  A UUID you generate per operation. Retrying with the same key returns the original response instead of repeating the operation. Recommended in production.
</ParamField>

### Request Body

<ParamField body="merchantCode" type="string" required>
  Your merchant account identifier.
</ParamField>

<ParamField body="name" type="string" required>
  Display name for the plan, e.g. `"Pro Monthly"`. Shown on invoices and the customer portal.
</ParamField>

<ParamField body="description" type="string">
  Optional description of what the plan includes. For internal reference and customer-facing display.
</ParamField>

<ParamField body="amount" type="integer" required>
  Billing amount in minor units (e.g. `999` = \$9.99 for a USD plan). Immutable after the first subscriber enrolls.
</ParamField>

<ParamField body="currency" type="string" required>
  ISO 4217 currency code, e.g. `"USD"`, `"EUR"`, `"BRL"`. Immutable after the first subscriber enrolls.
</ParamField>

<ParamField body="exponent" type="integer">
  Number of decimal places for the currency. Defaults to the ISO standard for the given currency (e.g. `2` for USD). Override for currencies with non-standard exponents.
</ParamField>

<ParamField body="interval" type="string" required>
  Billing interval unit. Accepted values: `"day"`, `"week"`, `"month"`, `"year"`. Immutable after the first subscriber enrolls.
</ParamField>

<ParamField body="intervalCount" default="1" type="integer">
  Number of interval units per billing cycle. For example, `3` with `"month"` creates a quarterly plan. Immutable after the first subscriber enrolls.
</ParamField>

<ParamField body="trialPeriodDays" type="integer">
  Number of days in the free trial. Subscribers start in `trialing` status and are not charged until the trial ends. Omit or set to `0` for no trial.
</ParamField>

<ParamField body="introAmount" type="integer">
  Discounted amount in minor units for the introductory period. Applies for the first `introBillingCycles` cycles before reverting to `amount`.
</ParamField>

<ParamField body="introBillingCycles" type="integer">
  Number of billing cycles that the `introAmount` applies to. Requires `introAmount` to be set.
</ParamField>

<ParamField body="maxBillingCycles" type="integer">
  Maximum number of billing cycles before the subscription automatically transitions to `completed` status. Omit for an indefinite subscription.
</ParamField>

<ParamField body="availableCountries" type="array">
  Array of ISO 3166-1 alpha-2 country codes that restrict where this plan can be used, e.g. `["US", "CA", "GB"]`. Omit or pass an empty array to make the plan available globally.
</ParamField>

## Response

Returns `201 Created` with the full plan object including the generated `id`.

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/subscription/plan \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "name": "Pro Monthly",
    "amount": 2999,
    "currency": "USD",
    "interval": "month",
    "trialPeriodDays": 14,
    "availableCountries": ["US", "CA"]
  }'
```

</RequestExample>
