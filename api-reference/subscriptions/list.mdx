---
title: "List and Filter Subscriptions"
sidebarTitle: "List Subscriptions"
description: "Retrieve a paginated list of subscriptions with filters for status, email, plan, card brand, and creation date range."
openapi: "GET /subscription"
---

`GET /subscription` returns a paginated list of your subscriptions. Filter by status, customer email or name, plan, card brand, or creation date range to narrow results. Results are returned in reverse-chronological order by creation date.

Filter and paginate with the query parameters in the panel above (`created_from`/`created_to` are inclusive ISO 8601 date bounds on `createdAt`). Response shape:

```json
{
  "data": [ ],
  "total": 142,
  "page": 1,
  "per_page": 20
}
```

<RequestExample>

```bash cURL
curl "https://api.therius.io/v1/subscription?merchantCode=MERCHANT_001&status=active&per_page=50" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{}
```

</ResponseExample>

<Tip>
  Combine `created_from` and `created_to` with `status=past_due` to identify subscribers who became overdue within a specific window — useful for targeted recovery campaigns.
</Tip>
