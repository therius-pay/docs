---

`POST /subscription/{id}/cancel` immediately cancels a subscription. This action fires the `subscription.cancelled` webhook event and cannot be undone — the subscription moves to `cancelled` status permanently. If you want to stop billing temporarily without losing the subscription, use [Pause & Resume](/api-reference/subscriptions/pause-resume) instead.

<Warning>
  Cancellation is permanent. There is no reinstate endpoint. If you need to re-enroll a cancelled customer, create a new subscription using `POST /subscription`.
</Warning>

## Request

**Base URL:** `https://api.therius.io/v1`

**Endpoint:** `POST /subscription/{id}/cancel`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer sk_live_xxx` (production) or `Bearer sk_sandbox_xxx` (sandbox) — your merchant private API key.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  A UUID you generate per operation. Retrying with the same key returns the original response instead of repeating the operation. Recommended in production.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The UUID of the subscription to cancel.
</ParamField>

### Request Body

<ParamField body="merchantCode" type="string">
  Your merchant account identifier.
</ParamField>

## Response

Returns `200 OK` with the updated subscription object. The `status` field will be `cancelled` and a `cancelledAt` timestamp will be set.

## Errors

| Code | Meaning |
| --- | --- |
| `400` | Subscription is already cancelled. |
| `404` | Subscription not found. |

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/subscription/sub_abc123def456/cancel \
  -H "Authorization: Bearer sk_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "merchantCode": "MERCHANT_001" }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{}
```

</ResponseExample>
