---
title: "Settle a Prior Authorization"
sidebarTitle: "Capture a Payment"
description: "Settle a previously authorized payment. Supports partial capture. Must be called within the acquirer authorization window."
openapi: "POST /payment/{id}/capture"
---

Call `POST /payment/{id}/capture` to settle funds from an earlier `POST /payment/authorization`. You can capture less than the full authorized amount — a partial capture — and the remaining hold is released automatically. You must call this endpoint within the acquirer's authorization window (typically 7 days) or the hold will expire and you'll need to re-authorize.

## Identifying the payment

`{id}` is the Therius payment `id` returned in the response to `POST /payment/authorization` (and `POST /payment/purchase`). Store it when you create the payment. `orderCode` and `paymentCode` are your own reference fields — they are **not** accepted as a way to address the payment for capture, refund or cancel.

An `id` that does not exist, or that belongs to another merchant, returns `404`.

## Request

**Endpoint:** `POST https://api.therius.io/v1/payment/{id}/capture`

### Path Parameters

<ParamField path="id" type="string" required>
  The Therius payment `id` from the authorization/purchase response.
</ParamField>

### Headers

<ParamField header="Authorization" type="string">
  Your secret API key as a Bearer token: `Bearer prv_production_xxx` (production) or `Bearer prv_sandbox_xxx` (sandbox).
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  A UUID you generate per operation. Required in production. Retrying with the same key returns the original response without creating a duplicate settlement.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json`.
</ParamField>

### Request Body

<ParamField body="merchantCode" type="string" required>
  Your merchant identifier.
</ParamField>

<ParamField body="reference" type="string">
  An optional internal reference for this capture operation.
</ParamField>

<ParamField body="amount" type="object" required>
  The amount to capture. May be less than or equal to the authorized amount.

  <Expandable title="amount fields">
    <ParamField body="currency" type="string" required>
      ISO 4217 currency code. Must match the currency of the original authorization.
    </ParamField>

    <ParamField body="value" type="integer" required>
      Amount in minor units. Must not exceed the originally authorized value.
    </ParamField>

    <ParamField body="exponent" type="integer" required>
      Number of decimal places for the currency.
    </ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="id" type="string">
  The Therius payment `id` (same value as the `{id}` path segment).
</ResponseField>

<ResponseField name="status" type="string">
  Result of the capture. One of:

  - `"captured"` — funds settled successfully.
  - `"failed"` — capture could not be processed. Check `connectionCode` and retry or contact support.
</ResponseField>

<ResponseField name="paymentCode" type="string">
  Therius receipt ID for this payment.
</ResponseField>

<ResponseField name="orderCode" type="string">
  Your original `orderCode`.
</ResponseField>

<ResponseField name="merchantCode" type="string">
  Your `merchantCode`.
</ResponseField>

<ResponseField name="amount" type="object">
  The amount actually captured, in `{ currency, value, exponent }` format.
</ResponseField>

## Example

### Full capture

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/payment/9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e/capture \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "amount": { "currency": "USD", "value": 9900, "exponent": 2 }
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "id": "9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e",
  "status": "captured",
  "paymentCode": "PC-1234567890",
  "orderCode": "ORDER-20240101-002",
  "merchantCode": "MERCHANT_001",
  "amount": { "currency": "USD", "value": 9900, "exponent": 2 }
}
```

</ResponseExample>

### Partial capture

```bash
curl -X POST https://api.therius.io/v1/payment/9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e/capture \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "amount": { "currency": "USD", "value": 7500, "exponent": 2 }
  }'
```

```json
{
  "id": "9f8b2c1e-4d5a-6b7c-8d9e-0f1a2b3c4d5e",
  "status": "captured",
  "paymentCode": "PC-1234567890",
  "orderCode": "ORDER-20240101-002",
  "merchantCode": "MERCHANT_001",
  "amount": { "currency": "USD", "value": 7500, "exponent": 2 }
}
```

<Note>
  When you perform a partial capture, Therius automatically releases the remaining hold (\$24.00 in the example above). You do not need to send a separate cancel request for the uncaptured portion.
</Note>

<Warning>
  You can only capture an authorized payment once. If you need to capture a different amount after a partial capture has already been processed, you'll need to create a new authorization.
</Warning>

<Tip>
  Always pass an `Idempotency-Key` on capture. If your server times out and you retry, the same key guarantees you won't double-settle the same authorization.
</Tip>
