O Therius é uma API de pagamentos que permite aceitar cartões, carteiras digitais e mais de 40 métodos de pagamento alternativos — Pix, ACH, iDEAL, Klarna, Apple Pay e mais — por meio de um único endpoint. Esta documentação cobre tudo, da sua primeira chamada em sandbox à gestão de assinaturas, ao tratamento de desafios de 3D Secure e à integração do SDK JS para uma coleta de cartões segura no navegador.

## Como o Therius funciona

Cada pagamento — cartão, carteira ou método alternativo — passa pelo mesmo endpoint `/payment/purchase`. Você escolhe o método de pagamento passando um campo `paymentMethod` (ou omitindo-o para cartões). A resposta sempre tem o mesmo formato, então o seu backend não precisa de caminhos de código separados por método.

<Steps>
  <Step title="Obtenha uma chave de sandbox">
    A sua conta do Therius inclui uma chave de sandbox (`prv_sandbox_...`) de fábrica. Ela roteia para um stub de provedor de teste — nada toca uma rede de cartão real.
  </Step>
  <Step title="Faça a sua primeira chamada de API">
    Envie a sua chave como `Authorization: Bearer prv_production_...` e dispare um `POST /payment/purchase`. Veja o [Início rápido](/quickstart) para um comando curl pronto para executar.
  </Step>
  <Step title="Integre o SDK JS (se for baseado em navegador)">
    Se você está aceitando cartões de um navegador, use o [SDK JS](/sdk/overview) para que os números de cartão brutos nunca transitem pelo seu servidor. O SDK emite um nonce de uso único; o seu servidor cobra o nonce.
  </Step>
  <Step title="Entre em produção">
    Troque `prv_sandbox_...` por `prv_production_...` e aponte para `api.therius.io`. Nenhuma outra mudança de código é necessária.
  </Step>
</Steps>
