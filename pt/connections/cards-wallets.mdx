Os pagamentos com cartão são o método padrão no Therius — omita `paymentMethod` por completo da sua requisição e um pagamento com cartão é assumido. As carteiras digitais usam o mesmo endpoint `POST /payment/purchase`, com um código `paymentMethod` e uma carga específica da carteira adicionada à requisição base. Todos os métodos de cartão e carteira suportam tanto cobranças únicas quanto recorrentes (de assinatura), salvo indicação em contrário.

<Note>
  Os métodos de carteira como Apple Pay e Google Pay exigem uma conexão configurada no seu painel do Therius. Entre em contato com o Therius para habilitar a descriptografia de carteiras para a sua conta de lojista antes de entrar em produção.
</Note>

### Cartão de crédito/débito — `card`

Os cartões são o padrão universal. Todas as moedas e países são suportados. Você pode omitir `paymentMethod` por completo ou defini-lo como `"card"` — os dois são equivalentes. Passe dados de cartão brutos no lado do servidor durante os testes; para checkouts baseados em navegador, use um nonce dos campos hospedados do SDK JS em vez de dados de cartão brutos para manter a sua integração fora do escopo de PCI.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 4999, "exponent": 2 },
  "card": {
    "cardData": {
      "cardNumber": "4111111111111111",
      "cardholderName": "Ada Lovelace",
      "expiryMonth": "12",
      "expiryYear": "2030",
      "cvv": "123"
    }
  }
}
```

### Apple Pay — `applepay`

O Apple Pay é suportado em iOS, macOS e Safari. Use `createWalletButton` do SDK JS para renderizar o botão do Apple Pay e abrir a folha de pagamento. O token de pagamento bruto devolvido por `ApplePaySession` vai em `walletData.token`. O Apple Pay suporta cobranças recorrentes.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "applepay",
  "walletData": {
    "type": "applepay",
    "token": "<base64 token from ApplePaySession>"
  }
}
```

### Google Pay — `googlepay`

O Google Pay funciona em Android, Chrome e qualquer navegador onde o comprador tenha um cartão salvo. Use `createWalletButton` do SDK JS para renderizar o botão e receber o token `PaymentData`. O Google Pay suporta cobranças recorrentes.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "googlepay",
  "walletData": {
    "type": "googlepay",
    "token": "<token from Google PaymentData>"
  }
}
```

### Click to Pay — `click_to_pay`

O Click to Pay é o esquema de cartões salvos em nível de rede da Visa/Mastercard, impulsionado pela CyberSource. O comprador seleciona um cartão de rede salvo sem digitar os dados do cartão. Use `createClickToPayButton` do SDK JS para renderizar o botão e obter um nonce.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "click_to_pay",
  "card": {
    "nonceData": {
      "nonce": "<nonce from createClickToPayButton>"
    }
  }
}
```

### PayPal — `paypal`

O PayPal suporta USD, EUR, GBP e muitas moedas adicionais. É um fluxo baseado em redirecionamento — o comprador é redirecionado ao PayPal para fazer login e confirmar. A resposta devolve `status: "pending_action"` com `actionRequired.url`.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "paypal"
}
```

### Venmo — `venmo`

### Alipay — `alipay`

O Alipay suporta CNY mais 13 moedas adicionais para transações transfronteiriças. Os compradores se autenticam no app do Alipay ou via QR code. A resposta devolve uma URL de redirecionamento ou uma carga de QR.

```json

  "orderCode": "ORDER-001",
  "amount": { "currency": "CNY", "value": 5000, "exponent": 2 },
  "paymentMethod": "alipay"
}
```

## Tokenização de carteira

Você pode salvar um método de pagamento de carteira para uso futuro — por exemplo, para cobrar um comprador de novo sem exigir que ele se autentique novamente. Para tokenizar uma transação de carteira, defina `walletData.tokenize: true` e inclua um `shopper.id` na sua requisição. O Therius armazena o token de carteira contra esse comprador e o torna disponível para cobranças posteriores.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": { "currency": "USD", "value": 5000, "exponent": 2 },
  "paymentMethod": "applepay",
  "walletData": {
    "type": "applepay",
    "token": "<base64 token from ApplePaySession>",
    "tokenize": true
  },
  "shopper": {
    "id": "SHOPPER-001"
  }
}
```

<Note>
  A tokenização de carteira exige um `shopper.id`. Sem ele, a flag `tokenize` é ignorada e nenhum token é salvo.
</Note>
