Cada método de pagamento no Therius passa pelo mesmo endpoint `POST /payment/purchase`. Você alterna entre métodos definindo o campo `paymentMethod` no corpo da sua requisição — ou omita-o por completo ao cobrar um cartão. Esta página é o seu ponto de partida para o catálogo completo de métodos de pagamento: navegue por categoria abaixo, ou use a tabela de consulta rápida para pular diretamente para um método específico.

<Note>
  Um método fica disponível para a sua conta assim que uma **conexão** que o suporta está configurada e habilitada no seu painel (veja [Roteamento inteligente](/concepts/smart-routing)). O catálogo abaixo é o conjunto completo que o Therius suporta — verifique a página **Conexões** no seu painel para ver o que está ativo na sua conta, e entre em contato com o Therius para habilitar um método que você não vê lá.
</Note>

## Como os redirecionamentos funcionam

A maioria dos métodos de pagamento alternativos (APMs) devolve um `status` de `"pending_action"` junto com um `actionRequired.url`. A sua integração deve redirecionar o comprador para essa URL para que ele possa concluir a autenticação ou o pagamento na página do banco ou da carteira dele. Depois que o comprador termina, o Therius o redireciona de volta para o seu `apm.returnUrl`.

Se você está usando o SDK JS do Therius, você não precisa tratar isso manualmente — chame `sdk.handleAction(result.actionRequired)` e o SDK gerencia o redirecionamento, aguarda o resultado e resolve a promise para você.

<Note>
  Alguns métodos de redirecionamento exigem campos adicionais na requisição — como `apm.returnUrl`, `apm.cancelUrl` ou dados do comprador como nome e e-mail. Esses requisitos são indicados na página de cada método.
</Note>

## Formato base da requisição

Cada requisição a `POST /payment/purchase` compartilha a mesma estrutura base. Você adiciona um código `paymentMethod` e um objeto específico do método (`card`, `apm` ou `walletData`) por cima dela.

```json
{
  "merchantCode": "MERCHANT_001",
  "orderCode": "ORDER-001",
  "amount": {
    "currency": "USD",
    "value": 5000,
    "exponent": 2
  },
  "paymentMethod": "<code>"
}
```

Os valores estão sempre em unidades menores. Para USD, `value: 1999` com `exponent: 2` equivale a $19.99. Para moedas sem decimais como JPY ou CLP, use `exponent: 0` e passe o valor inteiro completo.
