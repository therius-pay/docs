`POST /token` permite armazenar os dados de cartão como tokens reutilizáveis sem processar um pagamento. Use para pré-colocar cartões no vault durante fluxos de configuração de conta, ou para migrar cartões armazenados de outro provedor. Cada token é limitado à sua conta de lojista e armazenado com dados de BIN (bandeira, tipo, emissor).

<SchemaLangNote lang="pt" />

<Note>
  Para tokenizar um cartão durante um pagamento, adicione `card.cardData.tokenize: true` à sua requisição de pagamento em vez disso — veja [Conceitos de tokenização](/concepts/tokenization).
</Note>

## Requisição

**URL base:** `https://api.therius.io/v1`

**Endpoint:** `POST /token`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer sk_live_xxx` (produção) ou `Bearer sk_sandbox_xxx` (sandbox) — a sua chave de API privada de lojista.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Um UUID que você gera por operação. Repetir com a mesma chave devolve a resposta original em vez de repetir a operação. Recomendado em produção.
</ParamField>

### Corpo da requisição

<ParamField body="merchantCode" type="string" required>
  O seu identificador único de conta de lojista.
</ParamField>

<ParamField body="shopper" type="object">
  O cliente ao qual associar os tokens armazenados.

  <Expandable title="campos de shopper">
    <ParamField body="shopper.id" type="string">
      O seu identificador de cliente interno.
    </ParamField>

    <ParamField body="shopper.email" type="string">
      Endereço de e-mail do cliente.
    </ParamField>

    <ParamField body="shopper.name" type="string">
      Nome completo do cliente.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="tokens" type="array" required>
  Um array de entradas de token a armazenar. Cada entrada deve incluir `card.cardData` (campos de cartão brutos) ou `card.nonceData` (um nonce gerado pelo SDK).

  <Expandable title="campos de entrada de token">
    <ParamField body="tokens[].card.cardData" type="object">
      Dados de cartão brutos. Use apenas em ambientes no lado do servidor ou em conformidade com PCI. Para fluxos de navegador, prefira `card.nonceData`.

      <Expandable title="campos de cardData">
        <ParamField body="tokens[].card.cardData.cardNumber" type="string">
          Número de cartão completo (PAN).
        </ParamField>

        <ParamField body="tokens[].card.cardData.cardholderName" type="string">
          Nome como aparece no cartão.
        </ParamField>

        <ParamField body="tokens[].card.cardData.expiryMonth" type="string">
          Mês de validade de dois dígitos, p. ex. `"12"`.
        </ParamField>

        <ParamField body="tokens[].card.cardData.expiryYear" type="string">
          Ano de validade de quatro dígitos, p. ex. `"2030"`.
        </ParamField>

        <ParamField body="tokens[].card.cardData.cvv" type="string">
          Código de segurança do cartão.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="tokens[].card.nonceData" type="object">
      Nonce gerado pelo SDK no lugar de dados de cartão brutos. Recomendado para fluxos de navegador onde os dados de cartão são coletados pelo SDK JS do Therius.

      <Expandable title="campos de nonceData">
        <ParamField body="tokens[].card.nonceData.nonce" type="string">
          A string de nonce de uso único devolvida pelo SDK JS depois que o cliente digita o cartão dele.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="tokens[].expirationDate" type="string">
      Sobrescrita opcional da data de validade efetiva do token. Formato: `YYYY-MM`. Se omitida, a validade própria do cartão é usada.
    </ParamField>

    <ParamField body="tokens[].tokenCreationReference" type="string">
      A sua própria string de referência para esta entrada de token. Devolvida na resposta para conciliação.
    </ParamField>
  </Expandable>
</ParamField>

## Resposta

Uma requisição bem-sucedida devolve `200 OK` com o código de lojista, o objeto shopper devolvido e um array de entradas de token criadas.

<ResponseField name="merchantCode" type="string">
  O seu identificador de conta de lojista, devolvido da requisição.
</ResponseField>

<ResponseField name="shopper" type="object">
  O objeto shopper devolvido da requisição.

  <Expandable title="campos de shopper">
    <ResponseField name="shopper.id" type="string">
      O seu identificador de cliente interno.
    </ResponseField>

    <ResponseField name="shopper.email" type="string">
      Endereço de e-mail do cliente.
    </ResponseField>

    <ResponseField name="shopper.name" type="string">
      Nome completo do cliente.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tokens" type="array">
  Array de objetos de token criados, na mesma ordem que a requisição.

  <Expandable title="campos de token">
    <ResponseField name="tokens[].id" type="string">
      O ID de token reutilizável (com prefixo `vt_`). Passe-o como `card.tokenData.token` em futuras requisições de pagamento.
    </ResponseField>

    <ResponseField name="tokens[].card.cardData" type="object">
      Informações de cartão mascaradas armazenadas junto com o token.

      <Expandable title="campos de cardData mascarados">
        <ResponseField name="tokens[].card.cardData.brand" type="string">
          Bandeira da rede do cartão, p. ex. `"visa"`, `"mastercard"`.
        </ResponseField>

        <ResponseField name="tokens[].card.cardData.cardNumber" type="string">
          Número de cartão mascarado, p. ex. `"411111****1111"`.
        </ResponseField>

        <ResponseField name="tokens[].card.cardData.type" type="string">
          Tipo do cartão — `"credit"` ou `"debit"`.
        </ResponseField>

        <ResponseField name="tokens[].card.cardData.issuerName" type="string">
          Nome do banco emissor do cartão.
        </ResponseField>

        <ResponseField name="tokens[].card.cardData.issuingCountry" type="string">
          Código de país ISO 3166-1 alpha-2 do banco emissor.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="tokens[].expirationDate" type="string">
      Data de validade efetiva do token em formato `YYYY-MM`.
    </ResponseField>

    <ResponseField name="tokens[].tokenCreationReference" type="string">
      A sua string de referência, devolvida da requisição.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/token \
  -H "Authorization: Bearer sk_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "shopper": { "id": "customer-42", "email": "ada@example.com" },
    "tokens": [{
      "card": {
        "cardData": {
          "cardNumber": "4111111111111111",
          "cardholderName": "Ada Lovelace",
          "expiryMonth": "12",
          "expiryYear": "2030",
          "cvv": "123"
        }
      }
    }]
  }'
```

</RequestExample>

```json 200 OK
      "cardData": { "brand": "visa", "cardNumber": "411111****1111", "type": "credit" }
    },
    "expirationDate": "2030-12"
  }]
}
```

</ResponseExample>
