`GET /subscription` devolve uma lista paginada das suas assinaturas. Filtre por status, e-mail ou nome do cliente, plano, bandeira do cartão ou intervalo de data de criação para restringir os resultados. Os resultados são devolvidos em ordem cronológica inversa por data de criação.

<SchemaLangNote lang="pt" />

Filtre e pagine com os parâmetros de consulta do painel acima (`created_from`/`created_to` são limites de data ISO 8601 inclusivos sobre `createdAt`). Formato da resposta:

```json
{
  "data": [ ],
  "total": 142,
  "page": 1,
  "per_page": 20
}
```

<RequestExample>

```bash cURL
curl "https://api.therius.io/v1/subscription?merchantCode=MERCHANT_001&status=active&per_page=50" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{}
```

</ResponseExample>

<Tip>
  Combine `created_from` e `created_to` com `status=past_due` para identificar os assinantes que ficaram inadimplentes dentro de uma janela específica — útil para campanhas de recuperação direcionadas.
</Tip>
