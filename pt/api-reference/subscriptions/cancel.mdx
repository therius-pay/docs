`POST /subscription/{id}/cancel` cancela uma assinatura de imediato. Esta ação dispara o evento de webhook `subscription.cancelled` e não pode ser desfeita — a assinatura passa para o status `cancelled` de forma permanente. Se você quer parar o faturamento temporariamente sem perder a assinatura, use [Pausar e retomar](/api-reference/subscriptions/pause-resume) em vez disso.

<SchemaLangNote lang="pt" />

<Warning>
  O cancelamento é permanente. Não há endpoint de reativação. Se você precisar reinscrever um cliente cancelado, crie uma nova assinatura usando `POST /subscription`.
</Warning>

## Requisição

**URL base:** `https://api.therius.io/v1`

**Endpoint:** `POST /subscription/{id}/cancel`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer sk_live_xxx` (produção) ou `Bearer sk_sandbox_xxx` (sandbox) — a sua chave de API privada de lojista.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Um UUID que você gera por operação. Repetir com a mesma chave devolve a resposta original em vez de repetir a operação. Recomendado em produção.
</ParamField>

### Parâmetros de caminho

<ParamField path="id" type="string" required>
  O UUID da assinatura a cancelar.
</ParamField>

### Corpo da requisição

<ParamField body="merchantCode" type="string" required>
  O seu identificador de conta de lojista.
</ParamField>

## Resposta

Devolve `200 OK` com o objeto de assinatura atualizado. O campo `status` será `cancelled` e um timestamp `cancelledAt` será definido.

## Erros

| Código | Significado |
| --- | --- |
| `400` | A assinatura já está cancelada. |
| `404` | Assinatura não encontrada. |

<RequestExample>

```bash cURL

  -H "Authorization: Bearer sk_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "merchantCode": "MERCHANT_001" }'
```
