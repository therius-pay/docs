`GET /subscription/{id}` devolve o registro completo da assinatura para um UUID dado (veja o painel de resposta acima), com o plano dela incorporado em `plan`. O progresso de gestão de cobranças é reportado via `dunningAttemptCount` na própria assinatura, não um objeto aninhado — para o histórico de faturas, chame [Ver faturas](/pt/api-reference/subscriptions/invoices) com o mesmo `id` de assinatura; ainda não há um endpoint separado de linha do tempo de eventos de ciclo de vida.

<SchemaLangNote lang="pt" />

## Erros

| Código | Significado |
| --- | --- |
| `404` | Nenhuma assinatura encontrada para o `id` dado sob a sua conta de lojista. |

<RequestExample>

```bash cURL
curl "https://api.therius.io/v1/subscription/sub_abc123def456?merchantCode=MERCHANT_001" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>
