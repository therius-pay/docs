O Therius cria uma fatura por ciclo de faturamento. Cada fatura registra a tentativa ou as tentativas de cobrança para aquele ciclo, o resultado e o valor final cobrado. Você pode recuperar todas as faturas de uma assinatura, ou buscar uma fatura específica diretamente pelo UUID dela.

<SchemaLangNote lang="pt" />

## Liste as faturas de uma assinatura

`GET /subscription/{id}/invoice` devolve todas as faturas de uma assinatura dada em ordem cronológica inversa, como um array simples — veja o painel de resposta acima para a forma completa de `Invoice` (`status` é `open`/`paid`/`failed`/`void`; o campo de novas tentativas é `paymentAttemptCount`).

<a id="line-items" />

`lines[]` está presente apenas quando o plano precifica um ou mais [medidores de uso](/pt/guides/subscriptions#faturamento-por-uso-e-híbrido): uma linha para a tarifa base do plano (sem `meterId`) mais uma linha por complemento medido. Ausente ou vazio em uma fatura de tarifa fixa — o `amount` de nível superior é então a cobrança inteira, e o `amount` de cada linha soma a ele.

### Exemplo

```bash
curl "https://api.therius.io/v1/subscription/sub_abc123def456/invoice?merchantCode=MERCHANT_001" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

---

## Recupere uma fatura específica

`GET /subscription/invoice/{id}` recupera uma única fatura pelo UUID dela, independentemente de a qual assinatura ela pertence. Autentica da mesma forma que qualquer outro endpoint (`Authorization: Bearer prv_production_xxx` / `prv_sandbox_xxx`).

### Parâmetros de caminho

<ParamField path="id" type="string" required>
  O UUID da fatura a recuperar.
</ParamField>

### Parâmetros de consulta

<ParamField query="merchantCode" type="string" required>
  O seu identificador de conta de lojista.
</ParamField>

### Resposta

Devolve um único objeto de fatura com os mesmos campos descritos acima.

### Erros

| Código | Significado |
| --- | --- |
| `404` | Fatura não encontrada sob a sua conta de lojista. |

### Exemplo

```bash
curl "https://api.therius.io/v1/subscription/invoice/inv_xyz789abc?merchantCode=MERCHANT_001" \
  -H "Authorization: Bearer prv_production_your_key_here"
```
