`PATCH /subscription/plan/{id}` atualiza os campos mutáveis de um plano existente. Você pode renomeá-lo, atualizar a descrição dele, alternar o status ativo dele para parar de aceitar novos assinantes, ou ajustar os países onde ele está disponível — tudo sem afetar os assinantes existentes.

<SchemaLangNote lang="pt" />

<Note>
  `amount`, `interval`, `intervalCount` e `currency` são imutáveis e não podem ser alterados por este endpoint. Para mudar o preço ou a cadência de faturamento, crie um novo plano usando `POST /subscription/plan` e migre os assinantes usando [change-plan](/api-reference/subscriptions/change-plan).
</Note>

## Requisição

**URL base:** `https://api.therius.io/v1`

**Endpoint:** `PATCH /subscription/plan/{id}`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer prv_production_xxx` (produção) ou `Bearer prv_sandbox_xxx` (sandbox) — a sua chave de API privada de lojista.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Um UUID que você gera por operação. Repetir com a mesma chave devolve a resposta original em vez de repetir a operação. Recomendado em produção.
</ParamField>

### Parâmetros de caminho

<ParamField path="id" type="integer" required>
  O ID inteiro do plano a atualizar.
</ParamField>

### Corpo da requisição

Inclua apenas os campos que você quer mudar. Os campos omitidos ficam inalterados.

<ParamField body="merchantCode" type="string" required>
  O seu identificador de conta de lojista.
</ParamField>

<ParamField body="name" type="string">
  Nome de exibição atualizado do plano.
</ParamField>

<ParamField body="description" type="string">
  Descrição atualizada do que o plano inclui.
</ParamField>

<ParamField body="isActive" type="boolean">
  Defina como `false` para impedir que novos assinantes se inscrevam neste plano. Os assinantes existentes não são afetados. Defina de volta como `true` para reativar a inscrição.
</ParamField>

<ParamField body="availableCountries" type="array">
  Array atualizado de códigos de país ISO 3166-1 alpha-2. Passe um array vazio `[]` para tornar o plano disponível globalmente. Isso substitui a lista existente por completo.
</ParamField>

## Resposta

Devolve `200 OK` com o objeto de plano atualizado completo.

## Erros

| Código | Significado |
| --- | --- |
| `404` | Plano não encontrado. |
| `422` | Erro de validação — p. ex. um código de país não reconhecido ou uma tentativa de mutar um campo imutável. |

<RequestExample>

```bash cURL
curl -X PATCH https://api.therius.io/v1/subscription/plan/42 \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "name": "Pro Monthly (Revised)",
    "isActive": false
  }'
```

</RequestExample>
