`DELETE /subscription/plan/{id}` arquiva de forma suave um plano definindo o timestamp `deletedAt` dele. As assinaturas existentes no plano arquivado continuam faturando normalmente. Na próxima data de renovação de cada assinante, o Therius cancelará essas assinaturas em vez de renová-las. Nenhum assinante novo pode se inscrever em um plano arquivado.

<SchemaLangNote lang="pt" />

<Note>
  Isto é um soft-delete — a linha do plano não é removida de forma permanente, então ela permanece no banco de dados para fins de auditoria. No entanto, ela é **excluída dos resultados de lista de `GET /subscription/plan`** assim que arquivada (esse endpoint filtra os planos excluídos); consulte-a diretamente via `GET /subscription/plan/{id}` se precisar inspecionar um plano arquivado.
</Note>

Devolve `200 OK` com `{ "deleted": true }`.

## Erros

| Código | Significado |
| --- | --- |
| `404` | Plano não encontrado. |
| `409` | O plano já está arquivado. |

<Warning>
  Assim que um plano é arquivado, os assinantes existentes serão cancelados automaticamente na próxima renovação deles. Migre os assinantes para um novo plano usando [change-plan](/api-reference/subscriptions/change-plan) antes de arquivar se você quiser que eles continuem faturando sem interrupção.
</Warning>

<RequestExample>

```bash cURL
curl -X DELETE "https://api.therius.io/v1/subscription/plan/42?merchantCode=MERCHANT_001" \
  -H "Authorization: Bearer prv_production_your_key_here"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{ "deleted": true }
```

</ResponseExample>
