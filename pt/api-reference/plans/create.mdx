Os planos definem os termos de faturamento das assinaturas — valor, moeda, intervalo e período de teste opcional. Assim que um plano tem assinantes ativos, o `amount`, o `interval`, o `intervalCount` e a `currency` dele são imutáveis. Para mudar o preço ou a cadência de assinantes existentes, crie um novo plano e migre os assinantes usando [change-plan](/api-reference/subscriptions/change-plan).

<SchemaLangNote lang="pt" />

## Requisição

**URL base:** `https://api.therius.io/v1`

**Endpoint:** `POST /subscription/plan`

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer prv_production_xxx` (produção) ou `Bearer prv_sandbox_xxx` (sandbox) — a sua chave de API privada de lojista.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Um UUID que você gera por operação. Repetir com a mesma chave devolve a resposta original em vez de repetir a operação. Recomendado em produção.
</ParamField>

### Corpo da requisição

<ParamField body="merchantCode" type="string" required>
  O seu identificador de conta de lojista.
</ParamField>

<ParamField body="name" type="string" required>
  Nome de exibição do plano, p. ex. `"Pro Monthly"`. Exibido nas faturas e no portal do cliente.
</ParamField>

<ParamField body="description" type="string">
  Descrição opcional do que o plano inclui. Para referência interna e exibição voltada ao cliente.
</ParamField>

<ParamField body="amount" type="integer" required>
  Valor de faturamento em unidades menores (p. ex. `999` = \$9.99 para um plano em USD). Imutável depois que o primeiro assinante se inscreve.
</ParamField>

<ParamField body="currency" type="string" required>
  Código de moeda ISO 4217, p. ex. `"USD"`, `"EUR"`, `"BRL"`. Imutável depois que o primeiro assinante se inscreve.
</ParamField>

<ParamField body="exponent" type="integer">
  Número de casas decimais da moeda. O padrão é o padrão ISO para a moeda dada (p. ex. `2` para USD). Sobrescreva para moedas com expoentes não padrão.
</ParamField>

<ParamField body="interval" type="string" required>
  Unidade de intervalo de faturamento. Valores aceitos: `"day"`, `"week"`, `"month"`, `"year"`. Imutável depois que o primeiro assinante se inscreve.
</ParamField>

<ParamField body="intervalCount" default="1" type="integer">
  Número de unidades de intervalo por ciclo de faturamento. Por exemplo, `3` com `"month"` cria um plano trimestral. Imutável depois que o primeiro assinante se inscreve.
</ParamField>

<ParamField body="trialPeriodDays" type="integer">
  Número de dias no teste gratuito. Os assinantes começam no status `trialing` e não são cobrados até o teste terminar. Omita ou defina como `0` para nenhum teste.
</ParamField>

<ParamField body="introAmount" type="integer">
  Valor com desconto em unidades menores para o período introdutório. Aplica-se durante os primeiros `introBillingCycles` ciclos antes de voltar para `amount`.
</ParamField>

<ParamField body="introBillingCycles" type="integer">
  Número de ciclos de faturamento aos quais o `introAmount` se aplica. Requer que `introAmount` esteja definido.
</ParamField>

<ParamField body="maxBillingCycles" type="integer">
  Número máximo de ciclos de faturamento antes de a assinatura passar automaticamente para o status `completed`. Omita para uma assinatura indefinida.
</ParamField>

<ParamField body="availableCountries" type="array">
  Array de códigos de país ISO 3166-1 alpha-2 que restringem onde este plano pode ser usado, p. ex. `["US", "CA", "GB"]`. Omita ou passe um array vazio para tornar o plano disponível globalmente.
</ParamField>

## Resposta

Devolve `201 Created` com o objeto de plano completo incluindo o `id` gerado.

<RequestExample>

```bash cURL
curl -X POST https://api.therius.io/v1/subscription/plan \
  -H "Authorization: Bearer prv_production_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "merchantCode": "MERCHANT_001",
    "name": "Pro Monthly",
    "amount": 2999,
    "currency": "USD",
    "interval": "month",
    "trialPeriodDays": 14,
    "availableCountries": ["US", "CA"]
  }'
```

</RequestExample>
