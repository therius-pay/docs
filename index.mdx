Therius is a payment API that lets you accept cards, digital wallets, and over 40 alternative payment methods — Pix, ACH, iDEAL, Klarna, Apple Pay, and more — through a single endpoint. This documentation covers everything from your first sandbox call to managing subscriptions, handling 3D Secure challenges, and integrating the JS SDK for browser-safe card collection.

## How Therius Works

Every payment — card, wallet, or alternative method — flows through the same `/payment/purchase` endpoint. You choose the payment method by passing a `paymentMethod` field (or omitting it for cards). The response always has the same shape, so your backend doesn't need separate code paths per method.

<Steps>
  <Step title="Get a sandbox key">
    Your Therius account includes a sandbox key (`sk_sandbox_...`) out of the box. It routes to a test-provider stub — nothing touches a real card network.
  </Step>
  <Step title="Make your first API call">
    Send your key as `Authorization: Bearer sk_live_...` and fire a `POST /payment/purchase`. See the [Quick Start](/quickstart) for a ready-to-run curl command.
  </Step>
  <Step title="Integrate the JS SDK (if browser-based)">
    If you're accepting cards from a browser, use the [JS SDK](/sdk/overview) so raw card numbers never transit your server. The SDK issues a one-time nonce; your server charges the nonce.
  </Step>
  <Step title="Go live">
    Swap `sk_sandbox_...` for `sk_live_...` and point at `api.therius.io`. No other code changes required.
  </Step>
</Steps>
